# CMS User Guide

## Overview

The CMS is an administrative interface built for managing all portfolio content, including projects, achievements, certificates, work history, skills, media uploads, messages, and site configuration.

## Features

1. **Dashboard**:
   - Quick overview statistics (total projects, achievements, unread messages, media storage counts).
   - Recent messages feed with unread indicators.
   - Recent projects summary.

2. **Project Management**:
   - Create, edit, publish, draft, and archive projects.
   - Feature projects to display badges and top positions.
   - Attach cover images and gallery images stored directly in MinIO.
   - Categorization, tech stack tagging, problem/solution breakdown, and SEO metadata.

3. **Achievements & Certifications**:
   - Log awards, hackathon wins, scholarships, and certificates.
   - Attach image or PDF certificate proofs with modal preview viewer.

4. **Media Library**:
   - Upload images and documents to MinIO object storage.
   - Automatic WebP image optimization via Sharp.
   - Search, folder organization, inline rename, and bulk deletion.

5. **Contact Messages**:
   - Read incoming contact form submissions.
   - Mark as read, mark as replied, and direct `mailto:` integration.

6. **Site Settings**:
   - Configure global meta titles, site descriptions, contact emails, and maintenance mode toggle.
